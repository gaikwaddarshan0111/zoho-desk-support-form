Conversive Zoho Desk support form

1. Upload index.html and thank-you.html to your hosting document root under /support/.
2. Confirm https://conversive.in/support/ and https://conversive.in/support/thank-you.html open.
3. Submit ONE test form and verify that the ticket was created in Zoho Desk.
4. A redirect alone does NOT prove ticket creation.
5. Form fields currently included by Zoho: Last Name, Email, Subject. For Description, add it in Zoho Desk and regenerate the embed code.
6. Keep Zoho-generated hidden inputs, action URL, and scripts intact.
7. If the hosting provider is an external site builder, upload or paste the complete index HTML in a custom code page; scripts must be allowed.
8. The test page is marked noindex; confirm domain restrictions/CAPTCHA and authorization before production publication.
